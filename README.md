# دردشة — تطبيق Android أصلي (Kotlin + Jetpack Compose)

نسخة أصلية (Native) من `chat-v46.html` — **بدون WebView**. تتصل بنفس مشروع Supabase
(نفس الحسابات والجداول والـ buckets) فتعمل مع نسخة الويب جنباً إلى جنب.

## البناء عبر GitHub Actions (من KlencodIDE)
1. ارفع محتوى هذا المجلد إلى مستودع GitHub (الفرع `main`).
2. شغّل workflow باسم **Build Android APK** (يدوي فقط: Actions ← Build Android APK ← Run workflow).
3. حمّل الملف من Artifacts: `dardasha-debug-apk`.

الاعتماديات: Kotlin 2.0.21 · AGP 8.7.3 · Gradle 8.9 · Compose BOM 2024.12.01 · supabase-kt 3.0.3.
`minSdk 26` / `targetSdk 35`. لا يحتاج Gradle wrapper (الـ workflow يثبّت Gradle بنفسه).

## الميزات المنقولة
- تسجيل الدخول / إنشاء حساب (جلسة محفوظة)
- قائمة المحادثات + بحث + عدّاد غير المقروء + علامات الإرسال/القراءة
- محادثة فورية (Realtime): نص، صور (ضغط + عرض كامل)، رسائل صوتية (تسجيل m4a وتشغيل)
- رد على رسالة، تعديل، حذف للجميع / حذف عندي، تفاعلات إيموجي
- متصل الآن / آخر ظهور / "يكتب الآن..." (نفس قناة `room` في الويب)
- بدء محادثة جديدة بالبحث عن اسم مستخدم، حظر / إلغاء حظر
- الملف الشخصي: صورة، "حول"، تسجيل الخروج
- إشعارات محلية عند وصول رسالة والتطبيق في الخلفية (والعملية حيّة)
- واجهة RTL عربية بنفس ألوان نسخة الويب

## ميزات مضافة (v1.1)
- **إرسال المستندات**: أي ملف حتى 20MB (رفع إلى bucket `chat-files`)، والضغط على الملف يفتحه بتطبيق مناسب
- **مشاركة الموقع**: رابط خرائط داخل الرسالة مع بطاقة موقع (بعد تأكيد المستخدم)
- **تثبيت** (حتى 3) و**أرشفة** و**كتم** المحادثات: ضغط مطوّل على المحادثة في القائمة، أو من قائمة ⋮ داخل المحادثة
  - المكتومة: بلا إشعارات وعدّاد رمادي · المؤرشفة تعود تلقائياً عند وصول رسالة (إلا إذا كانت مكتومة)
- **رسائل بنجمة**: ضغط مطوّل على رسالة ← «تمييز بنجمة»، وشاشة «الرسائل المميّزة» من قائمة ⋮ في الرئيسية

> **مهم:** شغّل `supabase/features.sql` مرة واحدة في Supabase ← SQL Editor ليُنشئ جداول
> `chat_prefs` و`message_stars` وbucket `chat-files`. التثبيت/الأرشفة/الكتم/النجوم تعمل محلياً حتى بدونه،
> لكنها لا تتزامن بين الأجهزة، ورفع المستندات يحتاجه.
> إن كان bucket المستندات في نسخة الويب باسم آخر فغيّر `Repo.FILES_BUCKET`.

## غير منقول بعد
المكالمات الصوتية/الفيديو (WebRTC) · الحالات (Stories) · المجموعات والقنوات · منطقة Plus ·
قفل المحادثة بـ PIN · صور "مرة واحدة" · إعادة توجيه. إشعارات الخلفية الكاملة تحتاج Firebase (FCM) أو Supabase Edge Function.

## ملاحظات
- مفتاح Supabase في `data/Supa.kt` هو نفس المفتاح العام (publishable) الموجود في ملف HTML.
- الـ buckets المستخدمة: `chat-images` · `chat-audio` · `avatars`.
- لم يُجرَّ بناء فعلي أثناء كتابة المشروع (لا شبكة في بيئة الكتابة)؛ إن ظهر خطأ تجميع أرسل لي نص الخطأ من سجل Actions وأصلحه فوراً.
